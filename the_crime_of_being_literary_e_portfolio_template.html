2. How to Replace Literary Placeholders

Search for exact placeholder bracket strings in `index.html` (e.g. [YOUR FICTION WORK HERE]) and replace the text inside the containers with your prose or poetry. Paragraph breaks and whitespace will be preserved.

3. How to Add Google Docs URLs

In Destination 04 (Workshop) and Destination 05 (References), locate the <a href="..."> tags and replace the default URL with your actual shared Google Docs links.

4. How to Switch Ambient Visual Signatures

Use the top bar dropdown or change the JavaScript setting currentAmbient = 'motes' or 'eye' inside motion.js / main script block.

5. Deployment Instructions

GitHub & Netlify: Push this repository to GitHub. Link the repository to Netlify with build command left empty and publish directory set to /.
